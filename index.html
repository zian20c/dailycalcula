      FEATURES

      매일연산이 특별한 이유

      🎲

      매번 다른 숫자

      ‘다른 문제 뽑기’를 누를 때마다 문제가 새로 만들어집니다. 같은 유형을 오늘도 내일도 다른 숫자로 연습할 수 있어요.

      📚

      교과 진도에 맞춘 유형

      1학년 가르기·모으기부터 6학년 비례배분까지, 학년·학기·단원별로 정리된 다양한 유형 중에서 고르세요.

      🖨️

      A4 한 장에 딱

      문항 수와 글자 크기를 미리 재서 언제나 한 장에 맞춥니다. 두 장으로 넘어가는 일이 없어요.

      1234

      문제지번호로 정답 확인

      문제지마다 8자리 번호가 찍힙니다. 그 번호만 넣으면 똑같은 문제지의 정답을 언제든 다시 볼 수 있어요.

      🙋

      설치·가입 없이

      인터넷 연결도, 로그인도 필요 없습니다. 파일을 열기만 하면 PC에서도 휴대폰에서도 바로 동작해요.

      ✓

      정답 바로 보기

      화면에서 ‘정답 보기’를 누르면 답이 바로 채워집니다. 채점하면서 확인하기 편해요.

      HOW IT WORKS

      3단계로 쉽고 빠르게!

      고르고, 만들고, 인쇄하면 바로 끝납니다.

      1

      학년·단원 고르기

      학년과 학기, 단원, 유형을 차례로 고릅니다.

      2

      문제 뽑기

      문항 수를 정하고 누르면 숫자가 새로 만들어집니다.

      3

      인쇄하기

      A4 한 장으로 인쇄합니다. 정답지도 따로 뽑을 수 있어요.
